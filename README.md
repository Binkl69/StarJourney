# StarJourney

Fly the ISV *Meridian* from the cockpit. Steer through debris, nebulae and solar flares, route power between engines, shields and life support, patch the hull, and survive five legs to Halcyon.

- **Play:** open `index.html` in a browser (no build step, works offline). Built phone-first; keyboard works too.
- **Tune & add content:** `legs.js` (lane types, hazards, pickups, upgrades, comms, balance numbers).
- **Engine:** `flight.js` (3D flight, collisions, survival, HUD). 3D via three.js (MIT), bundled in `vendor/`.
- **Design:** [`docs/GAME_DESIGN.md`](docs/GAME_DESIGN.md) · earlier prototypes in `prototypes/`.
