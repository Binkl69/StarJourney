# StarJourney

You are the ISV *Meridian*'s control panel, 1980s style. Cross one living star system to land on Halcyon: balance the reactor, throttle with the faders, slingshot past a gas giant, build and strip rooms, send a drone through abandoned wrecks, and fight on radar, all from one console of green and amber phosphor screens.

- **Play:** open `index.html` in a browser (no build step, no libraries). Phone and desktop.
- **Content & tuning:** `data.js` (rooms, the orbiting star system, derelict layouts drawn as text, enemies, logs, balance).
- **Engine:** `console.js` (power & heat, rooms, navigation, drone exploration, radar combat, terminal, sound).
- **Design:** [`docs/GAME_DESIGN.md`](docs/GAME_DESIGN.md) · earlier prototypes in `prototypes/`.
