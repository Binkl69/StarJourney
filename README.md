# StarJourney

Fly the ISV *Meridian* through painted 2D space, cockpit instruments at your fingertips. Steer through debris, nebulae and solar flares, route power between engines, shields and life support, patch the hull, and survive five legs to Halcyon.

- **Play:** open `index.html` in a browser (no build step, works offline). Built phone-first; keyboard works too.
- **Tune & add content:** `legs.js` (lane types, hazards, pickups, upgrades, comms, balance numbers).
- **Engine:** `flight.js` (2D top-down flight on a canvas, sprites painted in code, collisions, survival, HUD). No libraries.
- **Design:** [`docs/GAME_DESIGN.md`](docs/GAME_DESIGN.md) · earlier prototypes in `prototypes/`.
